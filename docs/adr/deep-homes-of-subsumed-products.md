# Deep homes of subsumed products

Record 21 of the register. The index of the register sits in docs/decisions.md.

21. Deep homes of subsumed products. Made: 2026-11-13, issue 332, structure window. Decision: the summary and the law of a sub-entity stay in the docs tree, and the deep reference of the sub-entity lives in one deep home beside its code. A module earns a deep home when its reference passes its docs summary by about one screen, the Earn test. The dispatcher README is the standing case, the forgejo skill is the deep home of the hook, and the project binary gains a module home only when docs/project.md outgrows its summary. This record takes the place of the readme divergence of record 19, the no per-module readme files clause with its trigger of a module directory with its own consumer set: the trigger fired with this rule, and the Earn test replaces the flat no. Alternatives that lost: per-module readme files everywhere, because a module whose reference fits its summary needs none; every deep reference in docs, because the tree would carry the bulk that the one-topic law keeps out. Reopens: a module whose reference passes its summary by a screen and holds no deep home.
