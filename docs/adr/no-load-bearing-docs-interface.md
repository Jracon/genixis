# No documentation file is load-bearing for an interface

Record 20 of the register. The index of the register sits in docs/decisions.md.

20. No documentation file is load-bearing for an interface. Made: 2026-11-13, issue 332, structure window, keymap tier 1. Decision: the binding table left docs/keymap.md. The rows of lib/keymap.nix are the one list of the terminal bindings: the bind lines of tmux, WezTerm, and fish derive from the rows, the Option+K popup renders the rows, and keymap-table.awk retired. The nvim rows hold no derivation: they mirror the lua modules as an explicit supplement, and a change of the lua drags its row along. docs/keymap.md keeps the Terminal Law, the transport chain, and the conflict check of each binding. Reason: a documentation file is not an interface, and a table held only in a document drifts from the binds it describes. Alternatives that lost: the markdown table as the one list, because a document derives no interface; tier 2, a shared data file for the declarable nvim maps, because no drift event between a lua map and its supplement row has occurred; tier 3, generating the lua from Nix, because it would write lua inside Nix strings, void the plain-lua criterion of docs/cli.md, and break the headless probe procedure. Reopens: a drift event between a lua map and its supplement row, which takes tier 2; a second consumer of the binding rows.
