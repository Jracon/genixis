# Named documentation conventions

Record 19 of the register. The index of the register sits in docs/decisions.md.

19. Named documentation conventions. Made: 2026-11-12, issue 332, review window on structure. Decision: the documentation tree names the conventions it follows: the Diátaxis quadrants (https://diataxis.fr) and the record practice of architecture decision records (https://adr.github.io). Five questions of the Documentation Law map to the quadrants: what a topic is, how it is realized, and what it enables are reference; why it is that way is explanation; how a reader uses and changes it is how-to. A tutorial is the fourth quadrant; its home is docs/tutorial.md, one section per walkthrough, and a machine rebuild walkthrough comes first. Divergences that stay, each with its revisit trigger: the single-file register, because one read holds every standing decision, reopening at a concurrent append conflict or at 150 lines; supersession in the replace form, because every clone carries the history, reopening when replaced records are needed with no git present; no produced documentation site, because no produced tool configuration stands between a reader and the repository, reopening at a public audience that a file reader cannot serve; the verified dialect of record 6, reopening at a skill rule with no verdict; and no per-module readme files, because the repository is one configuration product, reopening at a module directory with its own consumer set. A pull request gate step checks documentation paths: a cited docs path must resolve, and every file of docs must be listed in AGENTS.md. Style sweeps in the gate stay deferred, reopening at a second documentation campaign. Alternatives that lost: a hosts directory and a darwin note, because the tree organizes by concept and platform facts live as sections of their topic files; per-record files for the register; status-flagged supersession; a produced site; house style guides in place of the verified dialect; and per-module readme files. Reopens: the triggers of the divergences above.
