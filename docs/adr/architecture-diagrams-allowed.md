# Architecture diagrams allowed where a structure outgrows prose

A record of the register, made 2026-11-23. The index of the register sits in docs/decisions.md.

Made: the owner, 2026-11-23, issue 639, stated in the windowed run of the worker leg of issue 637. The body of the issue holds the words of the owner: "we should amend that architecture diagram decision, they are necessary at a certain point and mkdocs-material makes it easy enough." Context: rejected entry 5 of the rejected list of docs/decisions.md banned architecture diagrams, C4 and mermaid among them, because diagram source is text but not plain prose, and plain reads stay first-class (the structure window of issue 332, 2026-11-12). The factory loop then grew past one prose view. Its sweep and spawn, the base guard of the branch, the bounds of the leg unit, the policy of the forge hook, and the roles of the legs sit in five files. The windowed run of issue 637 needed a chain of prose reads to hold one picture of the loop. The viewer already draws mermaid: the superfences config of mkdocs.yml names the fence. Decision: the register allows architecture diagrams where a structure outgrows prose. A diagram lives in the topic file of its structure, as mermaid source that the viewer draws. The source stays a plain read in the tree, and prose stays the first view of each structure. This record amends rejected entry 5 of the rejected list of docs/decisions.md. Alternatives that lost: the ban as it stood, because the loop outgrew it and the owner ruled the amendment. One image file per diagram, because an image is no plain read, and the mermaid source keeps the concern of the original entry. One diagram per subsystem, because the gap that the windowed run named is the one end-to-end picture. Consequences: the rejected entry names this record, so no reader takes the ban as standing law. The first diagram of the tree draws the factory loop end to end in docs/services.md. Documentation Law item 4 of docs/design.md keeps its force: the source of each diagram stays a plain read. Status: accepted. Reopens: the owner bans diagrams again, or the viewer stops drawing the mermaid fence.
