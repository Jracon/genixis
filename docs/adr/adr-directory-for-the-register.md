# An adr directory for the register

A record of the register, made 2026-11-13. The index of the register sits in docs/decisions.md.

Made: the owner, 2026-11-13, issue 362. Context: the register was one file, docs/decisions.md, and each new record appended after the last record. Record 19 held that shape as a stated divergence, with reopen triggers at a concurrent append conflict and at 150 lines. On 2026-11-13 the concurrent append trigger fired twice against pull request 361. Pull request 357 landed records 22 to 24 while the branch of pull request 361 held its own record 22. Pull request 359 then landed record 25 while the same branch held the merge policy record at 25. Each collision cost one merge of main, one renumber of the unmerged record, and one pass over the citations of the number. The review of pull request 361 found that concurrent campaigns collide again at the same anchor, so the shape itself is the defect. Decision: the register holds one file per record under docs/adr/. The file name is a slug, and it carries no number. A new record adds its file and one line of the index of docs/decisions.md. The number sequence ended at record 27. Records 26 and 27 landed through the old single file after this ruling, and this change ports them with their numbers. The earlier records keep their numbers as history, and the index maps each number to its file. A citation of a record names the record file. This record takes the place of the single-file clause of record 19, with its two reopen triggers. The one-read reason of that clause moves to the index: one read of the index holds every standing decision as a title. The other divergences of record 19 stand. Alternatives that lost: the single file with a rule for the concurrent append, because the number itself is the cost, and the append rate peaks when several review windows overlap. A number in the file name, because two branches that each append the next number produce two files, no git conflict, and one duplicate number. No gate rule checks record numbers. A number assigned at the merge of the pull request, or a date or a title in the citations, because the ruling chose the slug and ended the numbers (issue 362). Consequences: a record needs a second read after the index, and the index repeats each record title. The register stays one topic: docs/decisions.md is its home in the tree, and each record file holds one record, not one topic. The index line is the new append anchor. Two branches that each append one line can still meet at the anchor, and the resolution keeps both lines. No renumber and no citation move follows, because citations name files. The documentation path check matches docs paths with one segment and with two segments, and it requires each record file in the index (docs/ci.md). The record files are exempt as sources of that check, because each record is append-only and names historical paths. AGENTS.md names the directory with one line. The citations of the tree name the record files from this change. Status: accepted. Reopens: a conflict on the index that keeping both lines cannot settle, or an index that passes 150 lines.
