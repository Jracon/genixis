# The no-flakes entry point is cut

A record of the register, made 2026-11-19. The index of the register sits in docs/decisions.md.

Made: the owner, 2026-11-14, issue 393, the dispositions of the campaign. Context: principle 12 of issue 74 states total portability, and it allows a second entry point when the first one misses a machine. The stage 0 record of issue 166 extended the aim: an entry point for Nix without flakes is the end state. The extension has no consumer. No machine that works in this repository lacks Nix with flakes. The flake-compat shim of the plan needed a new flake input and a lock update (issue 74, the portability comment of the nudge leg of pull request 109), and the flake-compat entries of the lock today ride upstream inputs that this repository pins for other causes (docs/audit.md, the input-age pass). Decision: the no-flakes entry point is cut. Nix with flakes stays the floor of Stance item 5 of docs/design.md, which states the floor as it stands. No second entry point is planned. Alternatives that lost: build the flake-compat entry point, because no machine needs it and the Necessity Test of use removes it; defer with a trigger, because the plan carried the deferral since the stage 0 record and no trigger appeared. Consequences: a machine that works in this repository needs Nix with flakes and a checkout. The flake lock stays the one pin of every input. Status: accepted. Reopens: a machine without Nix with flakes that must work in this repository.
